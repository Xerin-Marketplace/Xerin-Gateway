# Phase 3 Task 14 — Promotions, Coupons and Campaigns

Patch contents are rooted under `phase3_task14_patch/` in the ZIP.

Install from the BACKEND directory:

```bash
unzip -o ~/Downloads/phase3_task14_promotions_complete.zip -d ~/Downloads/
cp -a ~/Downloads/phase3_task14_patch/. ~/Downloads/XERIM/BACKEND/
rm -rf ~/Downloads/phase3_task14_patch
```

Then activate the virtual environment, run Alembic, seed permissions and execute tests.
